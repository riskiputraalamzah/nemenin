# Nemenin — Ruang Aman untuk Merasa Ditemani

![Nemenin Banner](https://images.unsplash.com/photo-1573497620053-ea5300f94f21?q=80&w=1200&auto=format&fit=crop)

**Nemenin** adalah platform pendampingan emosional dan sosial yang hadir untuk menjembatani kebutuhan akan teman bicara, pendamping aktivitas, dan dukungan sosial yang profesional di Indonesia.

Kami percaya bahwa tidak ada seorang pun yang harus merasa sendirian. Nemenin menyediakan ruang aman di mana setiap interaksi didasarkan pada empati, privasi, dan batasan etika yang jelas.

---

## 🌟 Fitur Unggulan

### 1. **Teman Cerita & Pendamping Aktivitas**

Temukan partner yang tepat sesuai kebutuhanmu, mulai dari:

- 💬 **Teman Curhat**: Untuk _deep talk_ dan didengarkan tanpa penghakiman.
- 🎉 **Partner Kondangan**: Pendamping profesional untuk acara formal/sosial.
- 🎬 **Movie Buddy**: Teman nonton bioskop atau _hangout_ santai.
- 🎮 **Mabar Game**: Partner main game _rank push_ yang asik dan anti-toxic.

### 2. **Counselor Terverifikasi**

Keamanan adalah prioritas kami. Setiap _counselor_ atau pendamping di Nemenin telah melewati proses:

- ✅ Verifikasi Identitas (KTP)
- ✅ Background Check
- ✅ Pelatihan Dasar Empati & Kode Etik

### 3. **Privasi & Keamanan Terjaga**

- 🔒 Enkripsi data pribadi.
- 🛡️ Sistem anonimitas untuk sesi curhat.
- 🚫 Kebijakan _Zero Tolerance_ terhadap pelecehan dan pelanggaran etika.

### 4. **Fleksibel & Mudah**

- **Online**: Chat atau call kapan saja.
- **Offline**: Pertemuan tatap muka yang aman di tempat publik.
- **Jadwal**: Atur sesi sesuai waktu luangmu.

---

## 🛠️ Teknologi

Project ini dibangun menggunakan teknologi web modern yang ringan dan performant:

- **HTML5** - Struktur semantik.
- **Tailwind CSS** - Styling utility-first untuk desain responsif dan cepat.
- **JavaScript (Vanilla)** - Interaktivitas tanpa bloat framework berat.
- **Lucide Icons** - Ikonografi modern dan ringan.
- **Lenis Scroll** - Pengalaman _smooth scrolling_ yang premium.

## 🚀 Cara Menjalankan Project

1.  **Clone Repository**

    ```bash
    git clone https://github.com/riskiputraalamzah/nemenin.git
    ```

2.  **Buka Project**
    Buka folder `web/v1` di text editor favoritmu (VS Code disarankan).

3.  **Jalankan Live Server**
    Gunakan ekstensi **Live Server** di VS Code atau buka file `index.html` langsung di browser.
